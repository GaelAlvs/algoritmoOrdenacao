# 📚 Algoritmos de Ordenação

Projeto feito em grupo no 4° semestre do curso de Ciência da Computação, sob a disciplina de Estrutura de Dados.

## 🖥️ Tecnologias Utilizadas
- Linguagem de Programação [Java]
- Estruturas de Dados [Algoritmos]

## 🤔 Como funciona?

No projeto, foram utilizados 6 métodos de ordenação de dados, sendo eles:

- Bubble Sort
- Insertion Sort
- Selection Sort
- Merge Sort
- Quick Sort
- Heap Sort

Cada algoritmo possui vantagens e desvantagens em diferentes tipos de cenários, como por exemplo O(n²), Ω(n) ou Θ(n log n).
